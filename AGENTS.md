# library-tools

Repository: `clodhub/library-tools`. Checks, scaffolds, validates and publishes the clodhub component library; commands in `README.md`.
It sits at `tools/` in the workspace, beside `clod/`, `classes/`, `components/` and `recipes/`, and reads only the folders `library.json` lists there.
Owner: clodhub-dev. `scaffold_component.py` is edited together with foundation-components.
